                    HASHCATS GPU MINER - TERMINAL COMMANDS
                    Copy these commands ONE BY ONE to your GPU
════════════════════════════════════════════════════════════════════════


────────────────────────────────────────────────────────────────────────
COMMAND 1: Install Python and Dependencies
────────────────────────────────────────────────────────────────────────

sudo apt update && sudo apt install python3 python3-pip -y && pip3 install web3 eth-account pycryptodome requests numpy


────────────────────────────────────────────────────────────────────────
COMMAND 2: Check Your GPU (Optional but recommended)
────────────────────────────────────────────────────────────────────────

nvidia-smi


────────────────────────────────────────────────────────────────────────
COMMAND 3: Install GPU Support (if nvidia-smi showed your GPU)
────────────────────────────────────────────────────────────────────────

pip3 install pycuda


────────────────────────────────────────────────────────────────────────
COMMAND 4: Create the Miner File
────────────────────────────────────────────────────────────────────────

cat > miner.py << 'MINER_END'

[PASTE THE ENTIRE hashcats_miner.py CODE HERE]

MINER_END


Alternatively, use this method:
────────────────────────────────
nano miner.py

Then:
1. Paste the hashcats_miner.py code
2. Press Ctrl+X
3. Press Y
4. Press Enter


────────────────────────────────────────────────────────────────────────
COMMAND 5: Run the Miner
────────────────────────────────────────────────────────────────────────

python3 miner.py


When asked, enter your private key (starts with 0x)


────────────────────────────────────────────────────────────────────────
COMMAND 6: Run in Background (so you can close terminal)
────────────────────────────────────────────────────────────────────────

nohup python3 miner.py > mining.log 2>&1 &


────────────────────────────────────────────────────────────────────────
COMMAND 7: Watch the Logs
────────────────────────────────────────────────────────────────────────

tail -f mining.log


Press Ctrl+C to stop watching (miner keeps running)


────────────────────────────────────────────────────────────────────────
COMMAND 8: Check if Miner is Running
────────────────────────────────────────────────────────────────────────

ps aux | grep miner.py


────────────────────────────────────────────────────────────────────────
COMMAND 9: Stop the Miner
────────────────────────────────────────────────────────────────────────

pkill -f miner.py


────────────────────────────────────────────────────────────────────────
COMMAND 10: Restart the Miner
────────────────────────────────────────────────────────────────────────

pkill -f miner.py && nohup python3 miner.py > mining.log 2>&1 &

════════════════════════════════════════════════════════════════════════
                              TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

Problem: "command not found: pip3"
Solution: sudo apt install python3-pip -y

Problem: "No module named 'web3'"
Solution: pip3 install web3 eth-account pycryptodome

Problem: "Permission denied"
Solution: Add "sudo" before the command

Problem: "GPU not detected"  
Solution: That's okay! CPU mining still works (just slower)

Problem: "Connection refused"
Solution: Check your internet and RPC endpoint

Problem: "Insufficient funds"
Solution: Add ETH to your wallet on Robinhood Chain
