═══════════════════════════════════════════════════════════════
  HASHCATS GPU MINER - COPY/PASTE COMMANDS FOR TERMINAL
═══════════════════════════════════════════════════════════════

📋 RUN THESE COMMANDS ONE BY ONE ON YOUR GPU SERVER:


STEP 1: CHECK YOUR GPU
────────────────────────────────────────────────────────────
nvidia-smi


STEP 2: INSTALL DEPENDENCIES (Ubuntu/Debian)
────────────────────────────────────────────────────────────
sudo apt update && sudo apt install python3 python3-pip -y


STEP 3: INSTALL PYTHON PACKAGES
────────────────────────────────────────────────────────────
pip3 install web3 eth-account pycryptodome requests numpy


STEP 4: INSTALL GPU ACCELERATION (if nvidia-smi worked)
────────────────────────────────────────────────────────────
pip3 install pycuda


STEP 5: CREATE THE MINER FILE
────────────────────────────────────────────────────────────
nano hashcats_miner.py

Then paste the entire hashcats_miner.py code
Press: Ctrl+X, then Y, then Enter to save


STEP 6: RUN THE MINER
────────────────────────────────────────────────────────────
python3 hashcats_miner.py

Enter your private key when asked


STEP 7: RUN IN BACKGROUND (Optional - keeps running when you disconnect)
────────────────────────────────────────────────────────────
nohup python3 hashcats_miner.py > miner.log 2>&1 &


STEP 8: CHECK THE LOGS (if running in background)
────────────────────────────────────────────────────────────
tail -f miner.log


STEP 9: CHECK IF MINER IS RUNNING
────────────────────────────────────────────────────────────
ps aux | grep hashcats


STEP 10: STOP THE MINER
────────────────────────────────────────────────────────────
pkill -f hashcats_miner.py


═══════════════════════════════════════════════════════════════
  QUICK ONE-LINE SETUP (All steps 1-4 combined)
═══════════════════════════════════════════════════════════════

sudo apt update && sudo apt install python3 python3-pip -y && pip3 install web3 eth-account pycryptodome requests numpy pycuda


═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If "command not found":
    sudo apt install python3-pip -y

If "No module named 'web3'":
    pip3 install --user web3 eth-account pycryptodome requests numpy

If "Permission denied":
    Add sudo before the command

If GPU not working:
    The miner will use CPU automatically (slower but still works)

Check Python version (needs 3.7+):
    python3 --version
